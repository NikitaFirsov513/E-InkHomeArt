# E-InkHomeArt

Прошивка на ESP-IDF для домашней E-Ink-панели на ESP32-S3, с сенсорным экраном,
акселерометром LIS2DW12 и питанием от аккумулятора / USB-C.
Проект предназначен для открытой разработки прошивки; исходники платы в этот
репозиторий не входят. Сейчас код — стартовый пример ESP-IDF Hello World.

## Распиновка платы

Проверено 10.11.2026 по сохранённым схеме и PCB4: подключения ESP32 совпадают.
Модуль по схеме — ESP32-S3-WROOM-1U-N16R8 (16 МБ Flash, 8 МБ PSRAM).
В таблице указаны **номера GPIO ESP32-S3**, а не номера площадок модуля.
