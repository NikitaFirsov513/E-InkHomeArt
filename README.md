# E-InkHomeArt

Прошивка на ESP-IDF для домашней E-Ink-панели на ESP32-S3, с сенсорным экраном,
акселерометром LIS2DW12 и питанием от аккумулятора / USB-C.
Проект предназначен для открытой разработки прошивки; исходники платы в этот
репозиторий не входят. Сейчас код — стартовый пример ESP-IDF Hello World.

## Распиновка платы

Проверено 10.11.2026 по сохранённым схеме и PCB4: подключения ESP32 совпадают.
Модуль по схеме — ESP32-S3-WROOM-1U-N16R8 (16 МБ Flash, 8 МБ PSRAM).

## Конфигурация GPIO и периферии

Компонент `components/board` содержит единую конфигурацию платы:

- `include/board_pins.h` — все 22 GPIO, маски занятых, неподключённых и зарезервированных выводов.
- `include/board_config.h` — параметры интерфейсов и объявления конфигураций ESP-IDF.
- `board_config.c` — готовые структуры конфигурации и начальные уровни выходов.

| Интерфейс | Конфигурация |
| --- | --- |
| E-Ink SPI | SPI2, MOSI 45, SCLK 48, CS 47; стартовые mode 0 / MSB first / 1 МГц; DMA auto; блок до 4096 байт; MISO отключён |
| Общая I²C | I2C0, SDA 10, SCL 11; 100 кГц; внешние подтяжки; тайм-аут операций 100 мс |
| LIS2DW12 | 7-битный адрес `0x19` (SA0 на 3,3 В), INT1 на GPIO39 |
| ADC батареи | ADC1, канал 0, GPIO1; коэффициент пересчёта напряжения ×2 |
| ADC CC1 / CC2 | ADC1, каналы 7 / 2, GPIO8 / GPIO3; коэффициент ×1, последовательные резисторы не являются делителями |
| Общие параметры ADC | Oneshot, 12 бит, ослабление 12 дБ; пересчёт напряжения после калибровки |
| Отладочный UART | UART0, TX 43, RX 44; 115200, 8N1, без RTS/CTS |
| USB | Serial/JTAG на GPIO19/20; основная консоль, исключён из общей настройки GPIO |

Начальные уровни для будущей инициализации: CS дисплея = 1, оба RESET = 1,
DC = 0, LED = 0, затвор Q2 (`ETA_USB_DET`) = 0. Сначала нужно записать уровни
в выходные регистры, затем включать выходы и передавать SPI-пины периферии.
Кнопки POWER/BOOT активны при 0 и имеют внешние подтяжки. BUSY, touch INT
и LIS INT описаны как входы. GPIO-прерывания и внутренние подтяжки отключены.

Эти структуры — **только данные конфигурации**: `app_main` их ещё не применяет,
периферия не запускается. Драйверы UC8179, GT911 и LIS2DW12 уже добавлены к сборке;
их API, ограничения и источники описаны в [components/README.md](components/README.md).
Для GDEY075T7-T01 драйвер использует BUSY = 0; GT911 выбирает адрес `0x5D` либо
`0x14` при явном сбросе. Режимы прерываний и калибровку ADC настроим в коде запуска.
SPI 1 МГц — стартовая настройка, которую проверим на конкретной панели.

GPIO памяти не входят в маски периферии; неподключённые выводы автоматически
не настраиваются. GPIO0/3/45/46 — strapping-пины, перенастройка допустима
после считывания загрузочной конфигурации. S1 подключена к EN, отдельного GPIO нет.
Компиляция проверяет отсутствие конфликтов пинов, пересечения с памятью и
соответствие ADC-каналов выводам ESP32-S3.

Адрес акселерометра: [даташит LIS2DW12](https://www.st.com/resource/en/datasheet/lis2dw12.pdf), раздел I²C.

## Конфигурация и сборка

Проект настроен на **ESP-IDF 6.1** и **ESP32-S3 N16R8**. Настройки платы
хранятся в `sdkconfig.defaults`: Flash 16 МБ, QIO 80 МГц; Octal PSRAM 8 МБ,
80 МГц, инициализация и проверка памяти при запуске, доступ через `malloc()`.
Основная консоль — встроенный USB Serial/JTAG на GPIO19/20.
[Режимы Flash/PSRAM в документации Espressif](https://docs.espressif.com/projects/esp-idf/en/v6.1/esp32s3/api-guides/flash_psram_config.html).

В терминале с активированным ESP-IDF 6.1:

```sh
idf.py build
idf.py -p PORT flash monitor
```

`PORT` — порт платы. Если проект ранее собирался для другого чипа, сначала
выполните `idf.py set-target esp32s3`: команда пересоздаёт локальный `sdkconfig`.
Файл `sdkconfig` и каталог `build/` генерируются и не входят в Git.
Изменение `sdkconfig.defaults` не заменяет уже сохранённые значения `sdkconfig`.

Для отладки используется `board/esp32s3-builtin.cfg` и встроенный USB-JTAG;
на Windows для него может потребоваться драйвер WinUSB. В `.vscode/settings.json`
сохранены пути к локальным ESP-IDF и clangd: на другом компьютере выберите свою
установку ESP-IDF и поправьте `clangd.path` / `--resource-dir`.
База команд для анализа кода создаётся первой сборкой в `build/compile_commands.json`.
Контейнер разработки использует образ `espressif/idf:v6.1`.

Разметка Flash пока стандартная: NVS, PHY и один раздел приложения 1 МБ,
без OTA и файловой системы. Оставшееся место распределим при реализации панели.
Стартовый Hello World пока перезапускает устройство примерно каждые 11 секунд.
