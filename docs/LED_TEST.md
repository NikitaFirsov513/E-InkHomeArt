# Первый запуск: только D6

Режим по умолчанию для частично собранной платы. Приложение настраивает только
GPIO6 как выход и переключает его периодическим таймером: 500 мс включён,
500 мс выключен. Обработчик делает одну запись GPIO без ожидания и логирования;
отдельная задача приложения не нужна, `app_main` после настройки завершается.
В UART0 (TX43/RX44, 115200 бод) после загрузки появляется:

```text
LED TEST READY: D6 BLINK, 500 ms on / 500 ms off
```

PSRAM отключена, используются Flash и внутренняя RAM. Драйверы дисплея,
touch, акселерометра, ADC, управления зарядником и радиосвязи не запускаются.
Приложение не меняет eFuse. Полная диагностика сохранена отдельно:
[BRINGUP.md](BRINGUP.md).

## Минимальная сборка платы

- B1 — ESP32-S3-WROOM-1U-N16R8.
- C16 — 22 мкФ, C17 — 100 нФ: питание модуля.
- R16 — 10 кОм от EN к 3V3, C18 — 1 мкФ от EN к GND: надёжный запуск.
- R17 — 10 кОм от BOOT/GPIO0 к 3V3.
- D6 и R28 — 10 кОм, как в сохранённой схеме. Из-за R28 свечение может быть слабым.
- Доступ к UART J2 и цепям RESET/BOOT. S1/S2 можно временно заменить проводами.

Перед запуском проверить пайку и стабильные 3,3 В на питании B1. Аккумулятор
при обходе ETA6003 оставлять отключённым. Питание ESP32 подаётся через штатную
цепь 3V3; 5 В непосредственно на модуль или сигналы UART не подавать.
Первоначальный лимит 100 мА для пустого DC-DC может мешать запуску ESP32.

## Подключение без USB-разъёма платы

| USB–UART адаптер, уровни 3,3 В | Плата |
| --- | --- |
| TXD | J2.1 / DBG_RX / GPIO44 |
| RXD | J2.2 / DBG_TX / GPIO43 |
| GND | GND, например J3.2 |
| VCC | Не подключать; плата питается отдельно |

Для входа в загрузчик удерживать S2/BOOT (GPIO0 на GND), нажать и отпустить
S1/RESET (EN на GND), затем отпустить BOOT. При отсутствии кнопок используются
их сигнальные площадки и GND. После прошивки освободить BOOT и повторно
сбросить ESP32: оставленный на земле GPIO0 снова запустит загрузчик вместо LED-теста.

## Сборка и прошивка

В окружении ESP-IDF 6.1 из корня проекта. Отдельный `sdkconfig.led-test`
исключает сохранённые настройки старой диагностики при первой сборке:

```sh
idf.py -D SDKCONFIG=sdkconfig.led-test -D SDKCONFIG_DEFAULTS=sdkconfig.defaults build merge-bin -o E-InkHomeArt-led-test.bin
```

Результат — `build/E-InkHomeArt-led-test.bin`. Это объединённый образ с
загрузчиком, таблицей разделов и приложением; адрес записи **0x0**.
После ручного входа в загрузчик:

```sh
python -m esptool --chip esp32s3 -p COM7 -b 115200 --before no-reset --after no-reset write-flash 0x0 build/E-InkHomeArt-led-test.bin
```

COM7 заменить на порт адаптера. Сброс после записи выполняется вручную.
Проверка результата: D6 мигает, на UART есть сообщение `LED TEST READY`.
Если сообщение есть, а света нет, проверить полярность/пайку D6, R28 и уровень
GPIO6. Если сообщение отсутствует, проверить питание, EN, BOOT и UART.
Это программный тест запуска; он не подтверждает исправность ещё не собранных узлов.
